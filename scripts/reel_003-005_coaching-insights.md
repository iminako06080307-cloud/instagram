## #003 会食が多くても太らない3つのルール

> いちばんおすすめ。最初に撮るならこれ。

```
会食が多いのに太らない人は、
3つのことしかしていません。
【会食でも太らない3つのルール】

1つめ。
お酒と同じだけ、お水を飲む。
【① お酒と同じだけ、お水】

2つめ。
野菜から食べて、ご飯やパンは最後。
【② 野菜から食べる】

3つめ。
お腹いっぱいになったら、残していい。
【③ お腹いっぱいなら残す】

次の日に、ご飯を抜くのはやめてください。
いつもの食事で、2〜3日ゆるく整えれば大丈夫。
【次の日に抜くのはNG】

会食は、楽しんでいいんです。
保存して、会食の前に見てくださいね。
【保存してね】
```

## #004 食べてないのに痩せないのはなぜ？

```
食べる量を減らしているのに、
体重が減らない方。
それ、食べなさすぎかもしれません。
【減らしてるのに痩せない…食べなさすぎかも】

食べる量が少なすぎると、
体は「節約しなきゃ」と思って、
やせにくくなります。
【少なすぎると、体が節約モードに】

しかも50代は、
筋肉がどんどん減っていく年代です。
【50代は筋肉が減りやすい】

だから、毎食、
お肉なら手のひら1枚分。
お魚なら切り身1切れ。
しっかり食べてください。
【毎食 お肉は手のひら1枚分】

あなたに合う量を知りたい方は、
コメントに「量」と書いてくださいね。
【コメントに「量」と書いてね】
```

## #005 甘いもの、やめなくていいです

```
甘いもの、やめなくていいです。
そのかわり、半分にしてください。
【甘いものは、やめずに半分】

がまんすると、
あとで、もっと食べたくなりますよね。
【がまんすると、反動がくる】

お気に入りのお皿に、半分だけのせて、
好きなお茶と一緒に、ゆっくり食べる。
それだけで、ちゃんと満足できます。
【お気に入りのお皿に半分 ＋ お茶でゆっくり】

それから、果物。
シャインマスカットも、柿も、
じつは「おやつ」なんです。
【果物も、じつは「おやつ」】

がまんより、上手に楽しむ。
保存して、甘いものが欲しい日に見てくださいね。
【保存してね】
```

## 撮影のポイント（3本共通）

- 最初の1行は、動画が始まった瞬間に話し始める（無言の間を作らない）
- テロップは大きく、太く
- 「1つめ」「2つめ」は指で数を見せる
- 最後は画面の下を指さして「保存」や「コメント」をうながす
