## フィードバック動画からわかった、50代受講生さんの共通の悩み

※受講生さんのお名前・個別の数字はリポジトリに残さないよう伏せています。

| よくある悩み・つまずき | コーチが繰り返し伝えていること |
|---|---|
| **食べる量を減らしすぎて体重が動かない**（1200kcal前後まで落としてしまう） | 少なすぎると体が「省エネモード」になり、食べていないのに体重が動かない。必要な量は食べる |
| **たんぱく質が足りない**（朝が牛乳だけ、パンだけなど） | 50歳を過ぎると筋肉はどんどん減る。1食20g（肉なら手のひら大、魚なら切り身1切れ）。たんぱく質をとると食欲も安定する |
| **間食がやめられない**（大福、干し芋、プリン、果物） | やめなくていい。1日100kcalの「楽しむ余白」に収める。まずは半分にして、好きなお茶とゆっくり楽しむ |
| **果物はヘルシーだと思っている**（シャインマスカット、柿など） | 日本の果物は甘くておいしい分、糖質が高い。ダイエット中は「おやつ」扱い |
| **会食・外食が多い**（フレンチ、イタリアン、居酒屋、仕出し弁当） | 楽しんでいい。①お酒と同じ量の水 ②食物繊維 → たんぱく質 → 炭水化物の順 ③お腹いっぱいになったらやめる |
| **食べすぎた翌日にご飯を抜く** | 抜くとあとで食欲が乱れる。翌日から2〜3日、いつもの食事で脂質と糖質を少し控えめにすれば戻る |
| **「ヘルシー」なつもりで脂質をとっている**（油揚げ、卵を何個も、脂身つき豚ロース、納豆のタレ） | 脂質の少ないたんぱく質（鶏むね・ささみ・えび・いか・たこ）を選ぶ。卵は1日1個 |
| **かぼちゃ・芋・餃子の皮が炭水化物だと気づいていない** | それらがあるときはご飯を減らす（餃子5個ならご飯半分） |
| **歩けない日がある** | 1週間の平均で8000〜9000歩。雨の日は家の中で足踏みでも積み上がる |
| **完璧にできないと落ち込む** | 何十年も積み重ねてきた食事だから、戻っても大丈夫。毎食完璧じゃなくていい。淡々と続ける |

**ターゲット像との一致**: 会食・フレンチ・イタリアン・宅配食材（パルシステム）など、受講生さんは外食や付き合いが多く、食にお金をかけられる層。「我慢」より「楽しみながら調整」を求めている。

## 運用メモ

- **プログラムの強みが見えた**: 食事の写真を送る → 一食ずつ「完璧です」「ここだけ調整」と褒めながら直してもらえる、手厚い伴走型。リールでは売り込まず、「お悩みはDMで」「LINEで◯◯をプレゼント」で入口だけ作る
- **フィードバック動画の一部をそのまま使うのも有効**: 「実際の受講生さんへのアドバイスをお見せします」という型は信頼感が出る。その場合は**必ず受講生さん本人の許可をとり、名前・顔・体重などの個人情報を隠すこと**
- **「2週間で約2kg」などの成果を出す場合**も本人の許可をとり、「個人の結果です」と添える
- 1200kcal・1400kcalなどの具体的な数字は人によって違うので、リールでは出さないほうが安全（「あなたに合った量」としてDM・プログラムに誘導する）
